# 📐 대칭도형 마스터 챌린지 (Symmetry Quest)
> **초등학교 5학년 2학기 수학 3단원: 합동과 대칭** 학습용 웹 인터랙티브 게임

모눈종이 위에서 **선대칭도형**과 **점대칭도형**의 대응점을 찾아 도형을 완성하는 에듀테크 웹 애플리케이션입니다.
초등학생들이 직관적으로 수학적 개념(대칭축, 대칭의 중심, 대응점의 거리)을 체득할 수 있도록 시각 효과와 게임 요소를 결합했습니다.

---

## ✨ 핵심 기능

1. **3단계 레벨업 시스템 (5분 타임어택)**
   - **1단계 (기초)**: 세로/가로 대칭축을 기준으로 반으로 접었을 때 완전히 겹치는 **선대칭도형** 그리기
   - **2단계 (발전)**: 대칭의 중심(점 ㅇ)을 기준으로 180도 회전했을 때 완전히 겹치는 **점대칭도형** 그리기
   - **3단계 (마스터 챌린지)**: 선대칭과 점대칭 무작위 혼합, 대각선 대칭축($y=x$) 등 고난도 기하 챌린지

2. **교육적 피드백 & 순서 무관 완성**
   - 대응점을 어떤 순서로 찍든 알맞은 위치라면 자동으로 둘레를 따라 도형이 완성됩니다.
   - 틀린 점이 있을 경우 정답을 미리 알려주지 않고, **오답인 점만 빨간색으로 깜빡여 표시**하여 스스로 칸 수를 다시 세어 고칠 수 있도록 돕습니다.
   - 문제 해결 시 선대칭은 접히는 애니메이션, 점대칭은 **180° 부드러운 회전 애니메이션**을 통해 교과서 개념을 직관적으로 시각화합니다.

3. **학생 입장 & 교사용 실시간 관리자 페이지**
   - **학생 입장 화면**: 학생 별명과 선생님이 설정한 입장 비밀번호(기본값: `501`)를 입력하여 접속
   - **교사용 관리자 페이지 (기본 PIN: `1234`)**:
     - 입장 비밀번호 실시간 변경 및 원클릭 복사
     - 학생들의 득점, 진행 단계, 푼 문제 수, 최대 콤보를 **실시간 순위표**로 확인
     - 교실 TV/전자칠판용 **프로젝터 모드**, 시연용 모의 학생 생성, **엑셀(CSV) 다운로드** 기능 지원

4. **게임 요소 & 웹 오디오 효과음**
   - 점수, 연속 정답 콤보 배율, 아이템(돋보기 힌트, +30초 시간 연장, 2배 부스터, 가이드선 토글)
   - Web Audio API 기반 신시사이저 차임벨(딩동댕) 및 음소거 토글
   - 브라우저 로컬 저장소 기반 명예의 전당

## 🚀 GitHub Pages 1분 배포 방법

이 프로젝트는 Vite와 GitHub Actions 워크플로우(`.github/workflows/deploy.yml`)가 완벽하게 구성되어 있어 푸시만 하면 즉시 무료로 웹 사이트에 배포됩니다.

### 1. 새 깃허브 저장소 생성
1. [GitHub](https://github.com/)에 로그인 후 **New Repository**를 클릭합니다.
2. 저장소 이름을 입력합니다 (예: `symmetry-math-game`).
3. **Public**으로 설정하고 **Create repository**를 누릅니다.

### 2. 내 컴퓨터에서 코드 올리기 (Git Push)
터미널에서 아래 명령어를 차례대로 입력합니다:

```bash
# 1. 원격 저장소 연결 (본인의 깃허브 아이디와 저장소 이름으로 변경)
git remote add origin https://github.com/<본인의_깃허브_아이디>/<저장소_이름>.git

# 2. 메인 브랜치 설정 및 푸시
git branch -M main
git push -u origin main
```

### 3. GitHub Pages 활성화
1. GitHub 저장소의 **Settings** 탭으로 이동합니다.
2. 왼쪽 메뉴에서 **Pages**를 선택합니다.
3. **Build and deployment > Source** 항목을 **GitHub Actions**로 선택합니다.
4. 1~2분 뒤 생성되는 배포 주소(`https://<아이디>.github.io/<저장소이름>/`)로 접속하면 학생들과 함께 즐길 수 있습니다!
